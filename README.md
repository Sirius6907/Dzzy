# 🕷️ Dzzy

> A high-performance communication platform for human-agent collaboration.
> Forked from [block/dzzy](https://github.com/block/dzzy) and rebranded as Dzzy.

## Features

- **Real-time messaging** — WebSocket-based communication
- **AI Agent Integration** — Built-in support for AI agents
- **Multi-platform** — Desktop (Tauri), Mobile (Flutter), Web
- **Git Integration** — Repository management built-in
- **Workflow Engine** — Automate tasks with YAML workflows

## Quick Start

```bash
git clone https://github.com/Sirius6907/dzzy.git
cd dzzy
. ./bin/activate-hermit
cp .env.example .env
just setup
just relay
```
